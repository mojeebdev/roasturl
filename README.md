# 🔥🔥🔥RoastURL.xyz

> Drop your startup URL. Get a brutal AI audit in seconds.

Built by [@mojeebeth](https://x.com/mojeebeth) · [BlindspotLab](https://blindspotlab.xyz)

## Stack
- **Frontend**: Next.js 15 + TypeScript + Tailwind
- **AI**: Gemini 2.5 Flash Lite
- **DB**: Supabase (PostgreSQL)
- **Hosting**: Vercel (Serverless)



- 🔥  Brutal AI startup roast via Gemini 2.5
- 🔥  Roast Score (0–100) with visual meter
- 🔥  Shareable + downloadable card
- ⚡ 1hr result caching via Supabase
- 🔥 Edge case handling (unreachable, empty pages)
